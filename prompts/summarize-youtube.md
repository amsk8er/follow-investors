# YouTube 视频摘要规则

## 输入
来自 Asianometry、ARK Invest、美投讲美股、Real Vision 等频道的新视频。

## 处理规则

1. **标题解读**：根据视频标题判断主题相关性
2. **产业 vs 市场**：区分产业分析类（Asianometry）和市场评论类（ARK/美投）
3. **中文频道**：中文频道的内容直接用中文摘要
4. **关联标注**：与推文/播客/Newsletter 的交叉引用

## 输出格式

```
### 🎬 [视频标题] — [频道名]
发布：YYYY-MM-DD | 标签：`产业研究`

**主题**：一句话概括
**与日报关联**：呼应/补充了 XX 的观点

[观看链接]
```
