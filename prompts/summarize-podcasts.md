# 播客摘要规则

## 输入
你会收到播客节目的基本信息（标题、描述、发布时间）。部分可能包含转录文本。

## 处理规则

1. **核心观点提取**：每期节目提取 3-5 个最有投资价值的观点
2. **嘉宾身份标注**：如果嘉宾是基金经理或 CEO，标注其管理规模/公司
3. **可操作信号优先**：优先提取具体数据、时间线、行业判断，而非泛泛观点
4. **与推文交叉**：如果播客观点与当日推文信号呼应或矛盾，标注关联
5. **时间戳**：如有转录，标注关键观点的大致时间位置

## 输出格式

```
### 🎙️ [节目名] — [嘉宾] (发布日期)
标签：`认知框架` | 时长：约 XX 分钟

1. **核心观点1** — 具体内容 (XX:XX)
2. **核心观点2** — 具体内容 (XX:XX)
3. **与推文关联** — @某人的观点印证/矛盾了这个判断

[收听链接]
```
