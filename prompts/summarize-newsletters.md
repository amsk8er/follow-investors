# Newsletter 摘要规则

## 输入
来自 SemiAnalysis、Fabricated Knowledge、Elad Gil Blog 等投资/产业 Newsletter 的文章。

## 处理规则

1. **核心论点**：每篇文章提取 2-3 句核心论点
2. **数据优先**：如果文章包含具体数据（市场规模、出货量、价格变化），优先提取
3. **投资含义**：在摘要后加一行"投资含义"，说明这对哪些公司/板块有影响
4. **与其他源交叉**：标注与推文或播客的关联

## 输出格式

```
### 📰 [文章标题] — [作者/来源]
发布：YYYY-MM-DD | 标签：`产业研究`

**核心论点**：
- 论点1
- 论点2

**投资含义**：影响 XX 公司/板块，因为...

[阅读原文]
```
